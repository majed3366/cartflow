| ID | Law |
|----|-----|

| INV-FIG-02 | Figma parity is structural identity, not pixel-perfect screenshot matching. |
| INV-FIG-03 | Product truth and page responsibility override decorative parity. |
| INV-FIG-04 | Home and Decision Workspace remain the strongest identity anchors. |
| INV-FIG-05 | Carts / Communication / Settings share the product language without copying Home. |
| INV-FIG-06 | Mobile preserves approved identity structurally. |
| INV-FIG-07 | Incomplete truth may reduce density; it must not collapse into generic UI. |
| INV-FIG-08 | No approved Figma-mapped primitive may silently disappear without governance. |
| INV-FIG-09 | Legacy dashboard patterns remain prohibited. |
| INV-FIG-10 | Future visual change must preserve this traceability or explicitly supersede it. |
