## What this pack is

A **narrative system** for how CartFlow tells its story visually:

- What is the visual hero vs support vs atmosphere  
- How screenshots and devices behave  
- How 3D and motion may exist without becoming the story  
- Where silence builds trust  

## What this pack is not

- Not a design system (no colour, type, grid, components)  
- Not wireframes or Figma  
- Not screenshot selection/capture  
- Not 3D asset production  
- Not frontend implementation  

## Core laws

1. Product evidence outranks decoration.  
2. Devices are frames — not heroes.  
3. One Hero Object family per primary-evidence section.  
4. Dashboard UI is always the visual hero when present in LP-08.  
5. 3D must lose purpose if its Hero Object is removed.  
6. Motion guides attention only — no idle spectacle.  
7. Whitespace communicates confidence.
