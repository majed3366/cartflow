# Visual Story Rules V1

**Status:** Per-section visual narrative rules.  
**Date (UTC):** 2026-07-29  
**Parent:** Landing Page Visual Narrative V1  
**Related:** Storyboard V1 · Visual Object Hierarchy V1  

No layout. Roles and budgets only.

**Visual Noise Budget:** `None` · `Minimal` · `Low` · `Controlled` · `Inspect-critical` (noise must approach zero around Hero)

**Maximum Competing Elements:** Count of attention-worthy non-Hero objects allowed (excluding necessary Nav).

## Global story rule

At any scroll position, the merchant should answer within ~3 seconds:

1. What am I supposed to look at?  
2. Is it real product or decoration?  
3. Why should I believe the nearby claim?  

If (2) is decoration while a claim is product-capability, the section fails Visual Narrative.
