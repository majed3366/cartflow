# Motion and Depth Governance V1

**Status:** Binding motion and 3D/depth law for landing visual narrative.  
**Date (UTC):** 2026-07-29  
**Parent:** Landing Page Visual Narrative V1  
**Related:** Storyboard Visual Rhythm · Constitution Visual Evidence Law  

No asset creation. Eligibility and behaviour only.

---

## 1. Motion purpose (single)

Motion has **one purpose:** guide attention.

It may also support hierarchy, depth, and truthful state change — only when those serve attention to the correct object.

---

## 2. Permitted motion

| Type | Use |
|------|-----|
| Reveal | Bring Hero/Evidence into view on scroll |
| Transition | Soft section-to-section continuity |
| Focus | Emphasize the single Hero Object |
| Hierarchy | Secondary elements settle after Hero |
| Depth | Subtle parallax **only** if it does not move Hero content unreadably |
| State change | Journey steps, accordion open/close, evidence-state honesty |

---

## 3. Forbidden motion

- Continuous floating  
- Decorative spinning  
- Idle loops  
- Motion competing with screenshots  
- Motion replacing explanation  
- Background particle/network theatre  
- Pulse/urgency on CTAs  
- “Living” 3D mascots  
- Animating fake metrics counting up

## 5. 3D / depth role

3D (and depth treatments) exist only to:

- Add depth  
- Improve orientation  
- Support attention toward a Hero Object  
- Create atmosphere  

3D must never:

- Explain features  
- Replace screenshots  
- Introduce claims  
- Become the most memorable object  
- Imply AI/magic intelligence  

### Justification test (binding)

> Every 3D element must support a nearby Hero Object.  
> If the Hero Object is removed, the 3D object should lose its purpose.

Fail → remove 3D.

## 7. Depth without 3D

Preferred depth tools (still Atmosphere):

- Soft layered planes  
- Controlled shadow only if it aids hierarchy  
- Spacing / silence (primary)  

If depth reduces screenshot readability → forbidden.

---

## 8. Mobile motion & depth

| Rule | Mobile |
|------|--------|
| Same purpose | Guide attention only |
| Reduced budget | Prefer stillness around Hero Objects |
| No parallax that shifts UI text | Hard forbid |
| Full-width Hero | Depth frames collapse first |
| Accordion | Only required interactive motion in FAQ |

---

## 9. Trust expression through motion & depth

| Trust signal | How |
|--------------|-----|
| Confidence | Stillness + whitespace before Dashboard/Knowledge/CTA |
| Honesty | Calm reveal of insufficient-evidence states |
| Product reality | Screenshots settle without decorative motion |
| Non-desperation | CTA without pulsing urgency |

Motion that increases excitement without increasing understanding **fails** Visual Trust.
