# 02 — Information Hierarchy

Canonical question (owns the stage):

> ماذا حدث في التواصل مع العملاء، وما الذي يحتاج متابعتي الآن؟

Order inside PageStage:

1. **Orientation** — هل يوجد شيء يحتاجني الآن؟
2. **Status list** — أي حالة؟ ماذا حدث؟ هل CartFlow يتابع؟
3. **Detail / history** — ماذا حدث بالضبط؟
4. **Handoff** — أين أنفّذ إن لزم؟ → السلال فقط

Dominance:

- NEEDS_MERCHANT_RESPONSE is the only strong attention state.
- Automated / waiting rows are quieter.
- Completed / terminal does not compete with active work.
- Configuration block is orientation-level, not a fake customer follow-up.

One attention word: **يحتاج متابعتي**.
