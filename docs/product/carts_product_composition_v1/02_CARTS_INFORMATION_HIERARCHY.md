# Carts Information Hierarchy

Canonical question:

> ما السلال التي تحتاج انتباهي الآن، وما الإجراء التشغيلي المطلوب لكل سلة؟

Hierarchy (not analytics):

1. **ATTENTION** — compact orientation: is there work now?
2. **CART** — which customer/cart is in the queue
3. **STATE** — canonical attention / lifecycle label
4. **ACTION** — exactly one primary action

Forbidden on this page:

- KPI dashboard / conversion %
- strategic banner / MI story / MPL
- Workspace diagnosis / publication
- VIP threshold / policy fields
- fake counts or invented urgency

Orientation is compact so the queue appears immediately.

Desktop: orientation → master-detail (queue + selected detail).

Mobile: orientation + queue → selected detail → back to queue (selection retained).
