## What this pack is

Arabic **messaging architecture** that will later govern final copywriting:

- One message owner per LP section  
- Merchant state transitions  
- Claim ceilings and evidence coupling  
- Saudi/Gulf merchant language system  
- Blocked unsupported claims  

## What this pack is not

- No final Arabic headlines or paragraphs  
- No final CTA labels or FAQ answers  
- No redesign / Figma / wireframes  
- No screenshot selection / 3D / animation  
- No frontend or production change  
- No English→Arabic translation of a foreign landing  
- No pricing / plans / testimonials / fake metrics  

## Contradiction log

No genuine contradiction found with Constitution V1 or Information Architecture V1 at pack creation (see Copy Architecture §1). Future contradictions must be **documented**, not silently resolved by editing approved packs.
