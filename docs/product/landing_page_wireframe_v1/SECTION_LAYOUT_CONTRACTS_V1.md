# Section Layout Contracts V1

**Status:** Binding structural layout contracts per LP section.  
**Date (UTC):** 2026-07-29  
**Parent:** Landing Page Wireframe V1  

---

## LP-01 — Navigation

| Clause | Definition |
|--------|------------|
| **Layout Owner** | Brand + primary CTA cluster |
| **Layout Rule** | A single lightweight bar orients; it must never compete with the Hero for attention. |
| **Forbidden Layouts** | Mega-menu sales story; equal dual primary CTAs; promo badges |
| **Evidence Placement** | Alone — none |
| **Collapse Rule** | Anchors → menu; primary CTA remains |

---

## LP-02 — Hero

| Clause | Definition |
|--------|------------|
| **Layout Owner** | Headline |
| **Layout Rule** | The headline owns the first viewport; any product preview is subordinate and optional. |
| **Forbidden Layouts** | Preview larger than headline attention; 3D hero dependency; feature grid; dual heroes |
| **Evidence Placement** | After copy (mobile); beside only if ≤42% and subordinate (desktop) |
| **Collapse Rule** | Copy → CTA → preview stack; preview may drop below fold |
