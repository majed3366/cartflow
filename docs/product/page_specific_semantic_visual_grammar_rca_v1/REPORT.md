# Page-Specific Semantic Visual Grammar RCA V1 — Report

## Problem

Founder-visible evidence: semantic primitives behave like reusable glyphs across surfaces (especially Home ↔ Workspace attention / clause reuse), while Carts / Communication / Settings still risk generic list/card collapse.

## Root cause

Composition is not page-owned. Shared clause roles and shared chrome stand in for page meaning.

## Contracts (approved)

1. **Home — gravity well + satellites**  
   Board gravity is primary; monitors are satellites. No repeated `.cf2-co--attention` badge. No three-icon clause.

2. **Workspace — formation body**  
   Meaning in evidence → void → mass → terminus. READY = zero semantic icons. Conflict via relation/offset.

3. **Carts — weighted queue**  
   Rows are cart-objects. Actionable = mass + continuous start-edge. Wait = interrupted/dashed continuity. Incomplete = withheld mass (never title + pills + empty white card).

4. **Communication — lifecycle continuum**  
   send → delivery → response → wait → follow-up. Needs follow-up = held continuation + handoff terminus. Failed send = broken progression. Not chat / not Carts queue.

5. **Settings — quiet configuration ledger**  
   Joints: READY closed, NEEDS_SETUP open, PARTIAL half, READ_ONLY/UNAVAILABLE mute. No attention wedge / density / decision mass / queue language.

## Shared grammar (allowed)

start-edge · restrained teal · open-C remnants · asymmetry · silence · selected edge · page-specific density/mass/openness

Shared identical page-defining objects: **NOT** allowed.

## Outcome

Audit-only. Implementation candidate: `docs/product/page_specific_semantic_composition_v1/`.
