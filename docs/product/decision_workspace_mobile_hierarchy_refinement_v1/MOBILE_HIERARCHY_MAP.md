# Mobile Hierarchy Map V1

Target reading rhythm (mobile content stage):

```
Orientation          ← page question (kept, demoted)
        ↓
Decision             ← .cf2-ws__title (owns page)
        ↓
Evidence status      ← .cf2-ws__eyebrow (metadata under decision)
        ↓
Evidence             ← confidence + density field + live lines
        ↓
Meaning              ← understanding body (quieter)
        ↓
CartFlow confirm     ← .cf2-dmass--echo (confirmation, not hero)
        ↓
Your action now      ← terminus / wait state
        ↓
Future continuation  ← .cf2-ws__next («بعده»)
```

## First-viewport contract (390 / 430)

Must be immediately clear:

1. **ما القرار؟** — primary title  
2. **لماذا؟** — status + «الأدلة ما زالت محدودة»  
3. **اتجاه الدليل** — shipping-step evidence line  

Slight scroll reveals:

4. **ماذا يعني؟** — meaning  
5. **تأكيد CartFlow** — mass echo  
6. **ماذا أفعل الآن؟** — terminus
