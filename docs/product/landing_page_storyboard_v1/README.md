## What this pack is

The **storytelling rhythm** and **visual narrative sequence** the future design must follow:

- What the merchant thinks / feels / needs next  
- When product evidence is introduced  
- When broader understanding is earned (LP-09)  
- Where to pause, breathe, and inspect  
- Motion and 3D eligibility without designing assets  

## What this pack is not

- No wireframes or layouts  
- No Figma  
- No colours / typography / components  
- No final Arabic copy or headlines  
- No screenshot selection or capture  
- No 3D generation  
- No frontend implementation  

## Evidence timing (approved)

```text
Hero → optional restrained preview
Problem / Reframe / Journey → no primary product proof
Widget → FIRST primary product evidence
WhatsApp → SECOND
Dashboard → PRIMARY ops evidence (strongest inspect)
Knowledge → highest-value understanding evidence (identity earned)
Decision / Trust → summary / principles
CTA → no new evidence
```
