# Merchant Scroll Journey V1

**Status:** Behavioural emotional journey for the future landing page.  
**Date (UTC):** 2026-07-29  
**Parent:** Landing Page Storyboard V1  

No marketing language. Behavioural reasoning only.

---

## 1. Approved emotional flow

```text
Curiosity
        ↓
Recognition
        ↓
Understanding
        ↓
Hope
        ↓
Evidence
        ↓
Trust
        ↓
Discovery
        ↓
Confidence
        ↓
Decision
        ↓
Action
```

Mapped to sections:

| Emotion | Primary section(s) |
|---------|-------------------|
| Curiosity | LP-02 entry |
| Recognition | LP-02 exit → LP-03 |
| Understanding | LP-04 |
| Hope | LP-05 |
| Evidence | LP-06 → LP-07 |
| Trust | LP-08 (+ deepened at LP-12) |
| Discovery | LP-09 |
| Confidence | LP-10 → LP-11 |
| Decision | LP-13 → LP-14 → LP-15 entry |
| Action | LP-15 |

## 2. Transition contracts

### T1 — Arrival → Curiosity (into LP-02)

| Field | Definition |
|-------|------------|
| **Why continue** | Merchant arrived evaluating tools; needs to know if this page is relevant. |
| **Unanswered question** | Does this address something I already feel in my store? |
| **Required prior state** | Oriented enough to read (LP-01 done or ignored). |

---

### T2 — Curiosity → Recognition (LP-02 → LP-03)

| Field | Definition |
|-------|------------|
| **Why continue** | Problem felt familiar; depth not yet confirmed. |
| **Unanswered question** | Is the abandoned cart really the whole problem? |
| **Required prior state** | Recognition sparked — not dazzled by spectacle. |

---

### T3 — Recognition → Understanding (LP-03 → LP-04)

| Field | Definition |
|-------|------------|
| **Why continue** | Deeper problem created tension with current habits (reminders/discounts). |
| **Unanswered question** | Why isn’t what I already send enough? |
| **Required prior state** | Calm urgency — not fear/blame. |

---

### T4 — Understanding → Hope (LP-04 → LP-05)

| Field | Definition |
|-------|------------|
| **Why continue** | Reframe opened a gap: action without understanding is incomplete. |
| **Unanswered question** | Is there a connected way to work instead of isolated tactics? |
| **Required prior state** | Accepts incompleteness of action-only recovery without hating existing tools. |

---

### T5 — Hope → Evidence (LP-05 → LP-06)

| Field | Definition |
|-------|------------|
| **Why continue** | Outline creates desire for proof; explanation alone is insufficient. |
| **Unanswered question** | Does early understanding actually happen in the storefront? |
| **Required prior state** | Knows the path conceptually; not yet trusting claims. |

---

### T6 — Evidence (widget) → Evidence (WhatsApp) (LP-06 → LP-07)

| Field | Definition |
|-------|------------|
| **Why continue** | First proof raises the next operational gap: after exit. |
| **Unanswered question** | What happens when the customer leaves the site? |
| **Required prior state** | Believes in-store evidence is real. |

---

### T7 — Evidence → Trust (LP-07 → LP-08)

| Field | Definition |
|-------|------------|
| **Why continue** | Customer-side journey proved; merchant needs their own operating view. |
| **Unanswered question** | What will I actually see and run day to day? |
| **Required prior state** | Rejects “WhatsApp-only product” interpretation. |

---

### T8 — Trust → Discovery (LP-08 → LP-09)

| Field | Definition |
|-------|------------|
| **Why continue** | Operating trust creates openness to deeper value. |
| **Unanswered question** | Does this also help me understand patterns I couldn’t see? |
| **Required prior state** | Believes CartFlow is a real merchant surface. |

---

### T9 — Discovery → Confidence (LP-09 → LP-10)

| Field | Definition |
|-------|------------|
| **Why continue** | Understanding without decision value feels academic. |
| **Unanswered question** | How does this change what I do in the store? |
| **Required prior state** | Broader-than-recovery identity earned (not labeled). |

---

### T10 — Confidence → longer Confidence (LP-10 → LP-11)

| Field | Definition |
|-------|------------|
| **Why continue** | Worries tools are campaign spikes, not ongoing value. |
| **Unanswered question** | Does usefulness grow with real usage and evidence? |
| **Required prior state** | Can name practical decision outcomes. |

---

### T11 — Confidence → Trust principles (LP-11 → LP-12)

| Field | Definition |
|-------|------------|
| **Why continue** | Longer-horizon claims raise fear of invention / AI guessing. |
| **Unanswered question** | Will it admit when it doesn’t know? |
| **Required prior state** | Interested in continuity without needing hype. |

---

### T12 — Trust → Decision readiness (LP-12 → LP-13)

| Field | Definition |
|-------|------------|
| **Why continue** | Principle trust is not yet platform fit. |
| **Unanswered question** | Does this work with my commerce platform? |
| **Required prior state** | Believes CartFlow restrains itself. |

---

### T13 — Fit → Objection clearing (LP-13 → LP-14)

| Field | Definition |
|-------|------------|
| **Why continue** | Residual practical blockers remain (speed, WhatsApp, setup, self-serve). |
| **Unanswered question** | What still might go wrong if I start? |
| **Required prior state** | Knows honest platform status. |

---

### T14 — Objections → Decision/Action (LP-14 → LP-15)

| Field | Definition |
|-------|------------|
| **Why continue** | Story complete enough to choose a next step. |
| **Unanswered question** | What is the safe next action? |
| **Required prior state** | Major objections reduced; no urgency theatre required. |

---

### T15 — Action → Closure (LP-15 → LP-16)

| Field | Definition |
|-------|------------|
| **Why continue** | Optional verification/contact only. |
| **Unanswered question** | Where do I verify or contact? |
| **Required prior state** | Decision made or deferred calmly. |

## 4. Failure modes (journey breaks)

| Break | Symptom | Storyboard fix |
|-------|---------|----------------|
| Spectacle before proof | Merchant entertained, not convinced | Hero light; evidence delayed to LP-06+ |
| Feature catalogue | Scroll fatigue; no emotion | One purpose per section |
| Early category claim | Identity claimed not earned | Hold broader identity to LP-09 |
| Evidence collage too early | LP-05 becomes LP-06…08 | Outline only in LP-05 |
| CTA before trust | Pressure / bounce | CTA only after LP-12…14 |
| Fear copy in Problem | Defensive exit | Calm urgency only |
