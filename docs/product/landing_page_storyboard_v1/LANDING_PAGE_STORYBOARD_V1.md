# Landing Page Storyboard V1

**Status:** Governed product storytelling and visual-sequence definition.  
**Date (UTC):** 2026-07-29  
**Governing authorities:** Constitution V1 · Information Architecture V1 · Copy Architecture V1 · Evidence Readiness V1  

**Non-goals:** No wireframes. No Figma. No final Arabic copy. No screenshot selection/capture. No 3D assets. No colours, typography, layout, or components.

This document defines the **experience flow** — what the merchant thinks, feels, sees (by role), and why they continue — not visual appearance.

---

## 0. Evidence introduction map (approved)

| Stage | Section | Evidence role |
|-------|---------|---------------|
| Curiosity | LP-02 Hero | Small **restrained** product preview (optional) — never required, never 3D-dependent |
| Recognition | LP-03 Problem | **No product proof required** — situations / narrative |
| Understanding | LP-04 Reframe | **Concept only** |
| Hope (path) | LP-05 Journey | **Illustration / conceptual journey only** — not deep product proof |
| Evidence begins | LP-06 Widget | **FIRST primary product evidence** |
| Evidence continues | LP-07 WhatsApp | **SECOND primary product evidence** |
| Trust peak (ops) | LP-08 Dashboard | **PRIMARY product evidence** (strongest operating trust visual) |
| Discovery | LP-09 Knowledge | **Highest-value understanding evidence** (broader identity earned) |
| Confidence | LP-10 Decision | Evidence **summary / outcome** — not a new product tour |
| Continuity | LP-11 Continuous | Conceptual continuity; optional light reuse of prior anchors |
| Trust principles | LP-12 Trust | Evidence **principles** — behavioural honesty, not new spectacle |
| Practical fit | LP-13 Integrations | Text / status — not logo theatre |
| Objections | LP-14 FAQ | No new product evidence |
| Action | LP-15 CTA | **No new evidence** |
| Close | LP-16 Footer | Utility only |

**Rule:** Product evidence must not appear as a collage before LP-06. LP-05 must not steal LP-06…LP-09 depth.

## 4. Storyboard review

| Question | Answer |
|----------|--------|
| Is every section emotionally necessary? | Yes — chrome (01/16), story (02–05), evidence (06–09), value/trust (10–13), close (14–15). |
| Does any section slow the story? | LP-11 and LP-13 must stay light; LP-14 optional depth. LP-05 must not become a feature tour. |
| Strongest trust moment? | **LP-08 Dashboard** (ops trust) then **LP-12** (principle trust). |
| Strongest product moment? | **LP-08**; first product spike **LP-06**; highest-value understanding **LP-09**. |
| Where stop to inspect? | **LP-06, LP-07, LP-08, LP-09** — especially LP-08. |
| Where scroll faster? | LP-05 scan; LP-11; LP-13; FAQ skip; Footer. |
| Is LP-09 earned naturally? | Yes — after outline + three evidence layers + dashboard trust. |
| Is CTA emotionally justified? | Yes — after discovery, confidence, trust, fit, objections. |
| Mobile same emotional journey? | Yes — required; desktop only expands, never reorders the emotional sequence. |
