# Mobile Footprint Notes V1

## What was compressed

Only the **evidence density field** (`.cf2-evfield`) inside Decision Workspace mobile:

| Property | Language default (sparse) | Mobile Workspace after |
|----------|---------------------------|-------------------------|
| min-height | 100px | 0 |
| gap | 16px | 5px |
| padding | 10px 0 14px | 2px 0 3px |
| bar height | 4px+ | 3px |

## What was preserved

- Commerce in Motion identity (density bars)
- Living Route spine / nodes
- Decision hierarchy and order
- Copy and live evidence truth
- Desktop field metrics

## What was not touched

Shell, navigation, section order, APIs, projection, desktop composition rules.
