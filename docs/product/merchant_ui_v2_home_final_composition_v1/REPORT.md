# Merchant UI V2 — Final Home Product Composition V1

**Scope:** Home only  
**Law:** Merchant meaning first · frozen grammar second (sparing)

## Merchant 5-second test

Without knowing Commerce Objects, a merchant should read:

1. **What is happening?** — the dominant store condition (title + why)
2. **Why care?** — commercial consequence in plain Arabic
3. **Does CartFlow know enough?** — confidence line (e.g. الأدلة ما زالت محدودة)
4. **Act now?** — stance block answers wait vs act
5. **What next?** — one clear CTA

## Composition rules applied

- One primary scene (`الأهم الآن`)
- At most one silent Commerce Object mark
- No object rail / gallery / design vocabulary labels
- Evidence field silent; confidence is merchant sentence
- Secondary: اعرف الآن / راقب / ما زال يتعلّم
- Workspace untouched
