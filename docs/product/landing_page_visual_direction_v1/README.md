## What this pack is

How CartFlow should **feel** visually on the future landing:

- Calm operational premium  
- Product-first / trust-first  
- Evidence over decoration  
- Timeless restraint over trend  

## What this pack is not

- Not hi-fi Figma  
- Not component libraries  
- Not colour/typography token sheets (Brand Foundation owns tokens)  
- Not screenshot selection/capture  
- Not 3D asset production  
- Not frontend  

## Direction in one line

**Calm green operational premium — real product UI as hero, silence as confidence, no AI theatre.**

## Default 3D stance

The page may ship with **zero 3D** and still be on-direction if screenshots and whitespace are strong.

## Contradiction log

Brand Foundation “no cart logo / no 3D gloss” reconciled with landing supporting frames in `VISUAL_DIRECTION_V1.md` / `THREE_DIMENSIONAL_LANGUAGE_V1.md`.
