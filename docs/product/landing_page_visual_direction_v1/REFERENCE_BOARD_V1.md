# Reference Board V1

**Status:** Curated principles board — not for copying.  
**Date (UTC):** 2026-07-29  
**Parent:** Visual Direction V1  

Goal: extract **principles** that fit CartFlow’s calm operational premium.  
Do not mix unrelated styles into a collage identity.  
CartFlow remains unique: **Arabic-first merchant product evidence**, Brand Foundation green, story-earned intelligence.

---

## How to use this board

| Do | Do not |
|----|--------|
| Adopt structural calm, evidence hierarchy, silence | Copy palettes, logos, or component kits |
| Note how product UI is shown | Import trend aesthetics that fight Brand Foundation |
| Prefer timeless restraint | Assemble a “Stripe + Linear + Framer” mashup look |

---

## Stripe

| | |
|--|--|
| **Worth adopting** | Product-led storytelling; generous whitespace; screenshots as proof; calm confidence; section clarity |
| **Avoid** | Finance-global English tone as a template; over-polished abstract diagrams that replace real product; complexity that doesn’t fit merchant Arabic brevity |
| **Fit** | High — trust + product maturity |

---

## Linear

| | |
|--|--|
| **Worth adopting** | Extreme clarity; dark-calm restraint (as discipline, not mandatory dark mode); UI-as-hero; minimal chrome |
| **Avoid** | Developer-tool darkness as CartFlow default; dense keyboard-power aesthetics; purple/neon accents |
| **Fit** | Medium-high for restraint — not for palette or audience tone |

---

## Notion

| | |

| **Fit** | Medium — calm yes; illustration density no |

## Synthesis — CartFlow landing identity vector

From the board, CartFlow adopts:

1. **Stripe/Apple silence + product proof**  
2. **Linear/Raycast UI-as-hero discipline**  
3. **Notion approachability without illustration clutter**  
4. **Framer motion only as attention guidance**  

CartFlow rejects:

1. Developer-dark default  
2. Motion/spectacle identity  
3. Illustration-led SaaS  
4. AI/neon futurism  
5. Collage aesthetics  

**Unique CartFlow difference:** Gulf/Saudi merchant Arabic product story; recovery→understanding earned by Knowledge evidence; Brand Foundation green trust — not a copy of any reference above.
