# Three-Dimensional Language V1

**Status:** Governed 3D / depth language for landing atmosphere and frames.  
**Date (UTC):** 2026-07-29  
**Parent:** Visual Direction V1  
**Related:** Visual Narrative Motion & Depth · Brand Foundation (avoid 3D marketing gloss)  

**This phase does not generate 3D assets.**

---

## 1. Role of 3D

3D exists only to:

- Add quiet depth  
- Improve orientation  
- Support attention toward a Hero Object  
- Create calm atmosphere  

3D must never:

- Explain features  
- Replace screenshots  
- Introduce claims  
- Become the most memorable object  
- Imply AI / magic intelligence  
- Act as a second brand logo system  

### Justification test (binding)

> If the nearby Hero Object (product evidence) is removed, the 3D object must lose its purpose.

Fail → remove.

---

## 2. Allowed object classes

| Object | Role | Notes |
|--------|------|-------|
| Phone | Supporting frame | For widget/WA evidence only |
| Browser / storefront window | Supporting frame | Thin chrome |
| Soft store package / parcel | Atmosphere | Only if supports commerce context near evidence — never logo |
| Shopping cart (literal) | Atmosphere (rare) | **Not** brand mark; Brand Foundation forbids cart-as-identity — use sparingly or prefer abstract flow |
| Knowledge card (extruded lightly) | Supporting | Prefer real UI screenshot over 3D card |
| Message bubble | Atmosphere | Must not become WhatsApp brand theatre |

**Preference order:** real screenshot → quiet device frame → minimal atmosphere → no 3D.

---

## 3. Forbidden objects

- Abstract AI brains  
- Floating cubes / icosahedrons  
- Random spheres / particles  
- Decorative planets  
- Neon geometry  
- Robot mascots  
- Glowing node networks  
- Holographic dashboards  
- Trophy / rocket growth clichés  

---

## 4. Material language

| Property | Direction |
|----------|-----------|
| Finish | Matte preferred |
| Reflections | Soft, minimal |
| Realism | Neutral realism — not toy plastic, not chrome |
| Scale | Consistent across page |
| Lighting | Soft, shared with Art Direction |
| Colour | Compatible with Brand Foundation greens/neutrals — no parallel neon palette |

**Forbidden materials:** iridescent, cyber metal, lava-lamp glass, loud gradient plastics.

|---------|-----|

| LP-02 | None preferred; minimal atmosphere only if non-dependent |
| LP-03–04 | None |
| LP-05 | Minimal marks only |
| LP-06–07 | Framing only |

| LP-10–16 | None |

---

## 6. Density

- At most **one** atmosphere 3D idea near a section — usually zero.  
- Evidence climaxes: **zero** 3D.  
- Never a field of floating objects.  

---

## 7. Reconciliation with Brand Foundation

Brand Foundation: avoid 3D marketing gloss and shopping-cart identity.

Landing 3D Language: allows **quiet supporting frames** and rare commerce atmosphere under strict justification.

**Therefore:** treat 3D as optional spice at most — default page can ship with **zero** 3D and still pass Visual Direction if screenshots and whitespace are strong.
