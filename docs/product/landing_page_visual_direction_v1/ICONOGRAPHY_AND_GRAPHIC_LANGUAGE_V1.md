# Iconography and Graphic Language V1

**Status:** Graphic language for landing support visuals.  
**Date (UTC):** 2026-07-29  
**Parent:** Visual Direction V1  
**Brand icons:** Prefer `branding/cartflow_brand_foundation_v1/icons/` family when icons are needed.  

Icons support comprehension. They **never** replace screenshots.

---

## 1. Icon family

| Rule | Direction |
|------|-----------|
| Source | Brand Foundation process/dashboard icons as primary family |
| Mixing | **One** family only — no Lucide + Fluency + custom mashups |
| Metaphor | Operational clarity (attention, evidence, journey) — not AI sparkles |

---

## 2. Stroke vs filled

| Context | Preference |
|---------|------------|
| Inline UI / quiet lists | Stroke, consistent weight |
| Rare emphasis | Soft filled only if Brand icons already define it |
| Avoid | Dual conflicting weights on one section |

---

## 3. Roundedness

- Match Brand Foundation geometry language (soft rounded, not pill-chaos).  
- Corner language aligned with screenshot radius family.  
- Avoid toy-round “consumer app” icon blobs.  

---

## 4. Accent usage

- Accents follow Brand Foundation green system (tokens not redefined here).  
- Accent highlights hierarchy — not decoration stripes everywhere.  
- Never purple widget-legacy accents on landing.  

---

## 5. Illustration language

| Allowed | Forbidden |
|---------|-----------|
| Simple conceptual contrast diagrams (LP-04) | Stock SaaS people packs |
| Quiet journey step marks (LP-05) | Multi-style illustrations |
| None in LP-08/09 climaxes | Cartoon characters, robots |

Default: **illustration scarcity**.

---

## 6. Dividers & section separators

| Tool | Direction |
|------|-----------|
| Separators | Soft spacing bands preferred over hard rules |
| Rules/lines | Hairline only if needed; never dense newspaper grids |
| Rhythm | Follow Wireframe silence bands (before Dashboard, Knowledge, CTA) |

---

## 7. Background graphics

| Allowed | Forbidden |
|---------|-----------|
| Soft neutral fields | AI networks, circuit boards |
| Very subtle geometric calm | Loud gradients, mesh blobs as heroes |
| Brand-compatible green tint at low intensity | Section-by-section theme changes |

Backgrounds must not compete with screenshots.

---

## 8. Decorative limits

| Limit | Rule |
|-------|------|
| Icons per section | Prefer 0–3; evidence sections prefer 0 |
| Illustrations per page | Sparse; concept sections only |
| Badges / pills | Avoid clusters; Constitution clutter rules |
| Patterns | None as wallpaper behind UI |

---

## 9. CTA graphic language

- Primary CTA: clear, calm, Brand-aligned emphasis.  
- No glow rings, shake, or scarcity badges.  
- Secondary: quieter text/button — never equal weight.  

---

## 10. Extensibility

The same icon/graphic language should later extend to:

- Marketing subpages  
- Simple docs headers  
- Onboarding calm moments  

Without inventing a second illustration brand.
