# Art Direction V1

**Status:** Artistic direction for the future CartFlow landing page.  
**Date (UTC):** 2026-07-29  
**Parent:** Visual Direction V1  
**Brand:** Compatible with Brand Foundation calm green identity — tokens not redefined here.

---

## 1. Atmosphere

The page atmosphere should feel:

| Attribute | Direction |
|-----------|-----------|
| Calm | Low visual noise; quiet backgrounds |
| Focused | One dominant object per section |
| Premium | Quality through restraint, not gloss |
| Professional | Merchant-operational seriousness |
| Human | Arabic-readable UI; no cold sci-fi |
| Confident | Whitespace and stillness as signals |

**Emotional temperature:** Cool-neutral confidence — not cold laboratory, not warm hype carnival.

---

## 2. Contrast

| Mode | Where |
|------|-------|
| **Soft** | Problem, reframe, trust, FAQ, footer |
| **Balanced** | Hero, journey outline, decision, continuity |
| **High (local)** | Only where evidence requires attention — Widget, WhatsApp journey, **Dashboard**, Knowledge card edges/text |

Never: page-wide harsh contrast, neon outlines, or strobing emphasis.

CTA contrast: clear affordance, calm — not emergency red/urgency patterns.

---

## 3. Depth

| Level | Allowed? | Notes |
|-------|----------|-------|
| Flat | Yes (default for copy/FAQ/trust) | Prefer for silence sections |
| Semi-depth | Yes | Soft planes, light elevation under screenshots |
| Full theatrical 3D | **No** as page default | 3D only sparse Atmosphere/Supporting per 3D Language |

**Acceptable depth recipe:** soft layered planes + restrained screenshot elevation.  
**Unacceptable:** parallax playgrounds, floating object fields, deep cinematic lighting stages.

---

## 4. Surfaces

How product surfaces should appear when presented:

| Surface | Appearance direction |
|---------|----------------------|
| **Dashboard / Home / Workspace** | True product UI, current face, large, still, dominant; minimal or no device theatre |
| **Phone** | Only as quiet frame for customer/WA evidence; matte; correct proportion; never the memory |
| **Knowledge card** | Product-true card language; evidence/insufficient state visible; highly readable Arabic |
| **Browser / storefront window** | Thin useful chrome only when it proves “in-store”; otherwise crop to widget truth |
| **Laptop bezel** | Optional for dashboard; prefer content-first; collapse on mobile |

Surfaces must look like **the same CartFlow** the merchant will enter after signup — not a marketing skin.

---

## 5. Lighting

| Rule | Direction |
|------|-----------|
| Quality | Soft, neutral |
| Direction | Gentle, consistent across 3D/atmosphere |
| Avoid | Dramatic rims, neon gels, nightclub contrast, harsh specular “tech chrome” |

Lighting must never invent a different brand mood than the calm green product world.

---

## 6. Composition

### Screenshots + whitespace

- Evidence climaxes sit in **air** (Wireframe: silence before Dashboard / Knowledge / CTA).  
- Screenshot blocks **breathe** — do not pack secondary cards beside them.  
- Copy near evidence stays short so the eye returns to the UI.  

### Large visual blocks

- One block owns the section.  
- Secondary objects dock to edges or disappear.  
- Section rhythm alternates **inspect density** (06–09) with **quiet bands** (04 after, 11–13, 15 before).  

### Hero composition

- Brand-first / problem-first message plane.  
- Optional restrained preview — never a 3D composition dependency (Constitution + Wireframe).  

---

## 7. Material mood (non-token)

| Material feel | Use |
|---------------|-----|
| Soft paper/air backgrounds | Page atmosphere |
| Matte device shells | Supporting frames |
| Crisp UI pixels | Hero screenshots (sharp, not over-blurred) |
| Soft shadow | Single elevation language |

Avoid: liquid glass stacks, iridescent plastics, chrome robots.

---

## 8. Motion feel (art-level)

Motion should feel like **turning a page in a calm briefing**, not a product launch video.

- Reveal / settle  
- No idle floating  
- Dashboard prefers stillness  

(See also Motion & Depth Governance in Visual Narrative; this pack sets aesthetic temperament only.)
