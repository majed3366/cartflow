# Gate 2X — CEO Visual Review

**Principle:** CartFlow is an executive operating system for commerce. Recovery is one capability. Merchant understanding is the product.

## 30-second Home check

After opening Home, the merchant should answer:

1. How is the business performing?  
2. Which products deserve attention?  
3. Which decisions matter today?  
4. Whether recovery is helping?  
5. Whether communication is healthy?

**Without** learning scheduler state, queue size, or internal recovery process.

## Pass criteria

| Check | Pass when |
|-------|-----------|
| Home language | Store / business — not CartFlow internals |
| Carts teaser | No leading queue count as the conclusion |
| Decisions teaser | Business decision language («راجع…») |
| Feeling | «I understand my store.» |
