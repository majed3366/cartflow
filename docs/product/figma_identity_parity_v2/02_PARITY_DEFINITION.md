# 02 — What Figma Identity Parity means

Parity is **not** pixel-perfect equivalence.

| Axis | Pass condition |
|------|----------------|
| 1. Structural grammar | Open-C, start-edge, taper, scoop, capsule, board, Decision Object remain the family |
| 2. Semantic expressiveness | Visuals change when the seven semantic variables change; quiet stays empty |
| 3. Spatial composition | Executive scene / Decision Object / ops master-detail — not equal card grids |
| 4. Visual hierarchy | Home/Workspace strongest; ops quieter; one attention gravity |
| 5. Surface relationships | Shared language, different responsibility |
| 6. Signature geometry | Recognizable without logo or color |
| 7. Density / silence balance | Density = sufficiency; silence is Core Silence, not leftover whitespace |
| 8. Directionality | RTL start-edge / open continuation, not LTR SaaS chrome |
| 9. Mobile identity | Same grammar at 390, not a generic stacked fallback |
| 10. Logo-hidden coherence | One product family with brand name hidden |

Same product identity, same grammar, same visual logic, same hierarchy intention.
