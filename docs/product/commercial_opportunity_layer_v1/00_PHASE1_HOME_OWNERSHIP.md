## Insertion point (reversible)

After the operational gravity-well board (H2–H4), **before** floor/taper:

```
[ Operational Home — unchanged ]
[ Commercial Opportunity Layer V1 — NEW, flag-gated ]
```

Commercial block owns its own question:

«أين توجد أهم فرصة تجارية الآن؟»

So Home answers **two** questions without merging feeds.

## Must NOT enter Home yet

- Simulation / preview missions (discount lab, channel lab, cross-sell lab)
- Flat mission lists
- KPI strips as commercial “opportunities”
- Product Intelligence matrix
- Revenue Missions workflow UI

## PASS criteria for this map

- Operational attention path intact when flag OFF
- Commercial layer absent when flag OFF
- Commercial layer visually secondary to / distinct from operational board when flag ON
