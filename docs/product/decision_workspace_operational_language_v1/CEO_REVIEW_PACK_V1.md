## What changed (WP1–WP9)

| WP | Change |
|----|--------|
| **1 Priority** | Primary opens with one evidence-based priority sentence |
| **2 Structure** | Observation → Operational Meaning → Guidance → Execution (if ready) |
| **3 No repetition** | Removed separate “Can I act / readiness” face rows |
| **4 Observation first** | Never begins with an action |
| **5 Operational language** | Review / Open / Check — not “commercial judgement” |
| **6 Execution precision** | WHAT / WHERE / HOW / EXPECTED RESULT when executable |
| **7 Readiness** | NEEDS_MORE_EVIDENCE → no CTA, no fake action; show what CartFlow continues |
| **8 Card identity** | ملاحظة / توجيه / إجراء / مراقبة / فرصة / مخاطر / تنفيذ / نتيجة |
| **9 Playbook render** | Operating-manual tasks, not management slogans |
